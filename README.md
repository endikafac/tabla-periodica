# Tabla periódica infantil / Taula periodiko txikia

Static site (no build step). Open `index.html` or serve the folder with any static host
(GitHub Pages, Netlify, Cloudflare Pages, Vercel).

- `es/` and `eu/`: tabla, aprende, secretos, fichas, quiz, elemento (`elemento.html?n=26`)
- `assets/js/data.js`: 118 elements (symbol, ES/EU names, emoji, kid hint)
- `assets/js/facts.js`, `rich.js`, `molecules.js`, `learn.js`: detail data and texts (ES/EU)
- `descargas/`: PNG posters
- `poster.html?type=tabla|secretos&lang=es|eu`: renders the posters (screenshot at 2x)

Element names follow the RSEQ table.
